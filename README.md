# Копилка достижений юного робототехника

Веб-приложение (HTML + CSS + JavaScript) для отслеживания прогресса учеников
кружка робототехники: чек-лист из 12 практических достижений, XP и уровни,
значки по категориям, мини-тесты по теории, растущий робот-компаньон,
именной сертификат и панель педагога со сводной статистикой по группе.

Данные хранятся локально в браузере (localStorage) — сервер не требуется.

## Запуск

Просто открой `index.html` в браузере — либо через GitHub Pages, либо
двойным кликом с локального диска.

## Структура

- `index.html` — разметка
- `style.css` — оформление
- `script.js` — логика приложения
